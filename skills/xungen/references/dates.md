# 纪年换算

族谱和墓碑上的日期多用年号、干支和农历。用 `scripts/when.py` 换算到公历年份：

```bash
python3 scripts/when.py 光绪二十六年三月初五      # 1900，庚子
python3 scripts/when.py 道光庚子                  # 1840
python3 scripts/when.py 庚子年 --from 1800 --to 1950   # 1840 或 1900
python3 scripts/when.py 民国三十八年 昭和五年 康德元年
python3 scripts/when.py 虚岁73 --ref 2026         # 1954
python3 scripts/when.py 属虎 --age 80 --ref 2026  # 最接近的三个虎年
```

支持明、南明、后金和清的年号，民国，日本年号（台湾日治时期户籍），满洲国年号，干支、生肖和虚岁。脚本只算到年；要精确到某一天，查：

- 中研院“两千年中西历转换”：https://sinocal.sinica.edu.tw/
- 1901 年以后，也可以查香港天文台的公历与农历日期对照表：https://www.hko.gov.hk/sc/gts/time/conversion.htm

## 容易错的地方

- **农历年底跨年**：农历十一月、十二月（冬月、腊月）的日子，很多已经是下一个公历年的 1、2 月。脚本遇到这种月份会提醒。
- **虚岁**：出生当年算 1 岁，每过一个春节加 1 岁。墓碑上的“享年”“寿”多是虚岁。
- **年号和干支对不上**：说明有一处抄错，回原件看；脚本会提示矛盾。
- **年号用过了期**：清亡后有人继续写“宣统”，海外和台湾长期用民国纪年。脚本按顺推计算并提示。
- **生肖**：按农历年算，春节前出生的人属上一年的生肖。
- **同一年两个年号**：改元那年两个年号都可能出现，例如 1620 年既是万历四十八年，也是泰昌元年。
- **时辰**：墓碑上“某时生”的时辰对查人帮助不大，照抄进 `text` 即可。

## 写进 JSON

保留原文，同时写换算后的年份；只能估计时加 `approx`：

```json
"birth": {"text": "光绪二十六年三月初五", "year": 1900},
"death": {"year": 1958, "approx": true}
```
