# 把祖籍对到今天的地名

族谱、墓碑、档案里的地名都是当时的叫法。县可能改过名、并过、拆过，村可能合并或消失。先把每条地名对到“事件发生时的行政区划”，再对到今天的地名，最后才去对应的档案馆、图书馆找。

## 几个容易混的说法

- **祖籍**：家族认定的老家，可能是几代以前的地方。
- **籍贯**：户口和档案上的籍贯通常跟父亲，未必是本人出生地。
- **出生地**：本人实际出生的地方。

问长辈时把三者分开问。

## 行政层级大致怎么变

| 时期 | 常见层级 |
|---|---|
| 明清 | 省—府（直隶州）—县（州、厅）—乡、都、图、保甲—村 |
| 民国 | 省—县—区—乡镇—村 |
| 1949 年以后 | 省—地区（地级市）—县—人民公社—大队—生产队，后改为乡镇—村 |

族谱写“某府某县某都某图”，今天要先找到县，再在县志里找“都”“图”下属的村。

## 一个例子

台山在 1914 年以前叫新宁县。族谱写“新宁县”，海外档案写 Sunning 或 Sun Ning，今天要去台山市查。

## 工具

| 要做的事 | 用什么 |
|---|---|
| 查清代以前某个地名在哪、属于哪个府州 | 中国历史地理信息系统 CHGIS（哈佛与复旦合作，覆盖公元前 221 年至 1911 年）在线地名查询：https://tgaz.fudan.edu.cn/tgaz/indexEngVer.html |
| 查今天的行政区划和 1949 年后的县级以上变更 | 民政部全国行政区划信息查询平台：http://xzqh.mca.gov.cn/ |
| 查一个县的沿革、乡镇和村名变化 | 新编县志的“建置沿革”“行政区划”章节，地名志 |
| 查某县有哪些旧方志、藏在哪里 | 中研院“中國大陸各省地方志書目查詢系統”；各省地方志网站目录可参考 https://gitee.com/hdeping/difangzhi |
| 找已经消失或改名的村 | 县志、地名志、旧地图，问乡镇政府或村委会 |

## 海外档案里的祖籍拼法

早期出洋的广东人多来自珠江三角洲，外国档案用粤语拼写县名：

| 档案常见拼法 | 县名（今天） |
|---|---|
| Sunning、Sun Ning、Toishan、Hoishan | 新宁（台山） |
| Hoiping | 开平 |
| Sunwui、Sun Wui | 新会 |
| Yanping | 恩平 |
| Heungshan、Chungshan | 香山（中山） |
| Namhoi | 南海 |
| Poon Yue、Punyu | 番禺 |
| Shuntak | 顺德 |

台山、开平、新会、恩平合称“四邑”，南海、番禺、顺德合称“三邑”。美国、加拿大、澳洲早期华人中这几地的人很多。福建、潮汕、客家地区的移民在南洋更多，拼法按闽南话、潮州话、客家话。

## 记录格式

在 JSON 里，地名照原文写，再括号注今天的地名：

```json
"birth": {"text": "同治十二年", "year": 1873, "place": "广东省新宁县（今台山市）某村"}
```

对不上的地名不要猜，写“待考”，把它列进待查清单。
