# 名字、字辈和谱中用语

## 一个人可能有好几个名字

| 名称 | 说明 | 记到 JSON 的哪里 |
|---|---|---|
| 名 | 日常用名 | `name` |
| 谱名 | 按字辈取、写进族谱的名字，可能和日常用名不同 | `pu_name` |
| 字、号 | 成年后取的字，文人常有号 | `zi`、`hao` |
| 小名、乳名 | 家里叫的名字 | `alt_names` |
| 外文名 | 海外档案里的拼写，如 Chan Chun Wah | `alt_names` |
| 讳 | 墓碑、牌位上“讳某某”指本名 | `name` 或 `pu_name` |

同一个人在族谱、墓碑、档案里可能名字都不一样。先按生年、父名、村名确认是不是同一人，再合并。

## 字辈

字辈（也叫行辈字、派语、字派）是一首或几首诗，每代按顺序用一个字取名，同一代人名字里有同一个字，位置多在名字的第一字或第二字。

用法：

- **判断代数**：知道字辈诗和某人在哪个字，就知道他是第几世。
- **找同宗线索**：同姓、同祖籍、同字辈诗是很强的线索，但不是证据；不同支派也可能用同一首诗，同一族续修时也可能换新诗。
- **发现问题**：名字不合字辈，可能是另有谱名、过继、抄错，或这一支不按字辈取名。`family.py check` 会提示。

在 JSON 里写：

```json
"zibei": {"start_generation": 15, "chars": "德振家声远", "source": "s1"}
```

`start_generation` 是诗里第一个字对应的世代。

## 女性

- 旧谱多只记“某氏”，例如“配黄氏”就是娶了黄家的女儿。墓碑和牌位上“陈门黄氏”“陈黄氏”指嫁到陈家的黄姓女子。
- 女儿常常不入谱，或只写“女一，适某村某某”（适＝嫁给）。要查女性祖先，靠户口簿、婚书、墓碑、娘家的谱。
- JSON 里写 `"name": "黄氏", "surname": "黄"`；知道全名就写全名。

## 谱中常见用语

| 用语 | 意思 |
|---|---|
| 配、娶 | 妻子 |
| 继配、续娶 | 原配去世后再娶的妻子 |
| 侧室、副室 | 妾 |
| 适 | 女儿出嫁到某家 |
| 出继、出嗣 | 过继给别房，生父母一支不再记他的后代 |
| 入继、嗣子 | 从别房过继来的儿子 |
| 兼祧 | 一个儿子同时承两房香火 |
| 赘、入赘 | 男方到女家生活，子女可能从母姓 |
| 殇、夭 | 未成年去世 |
| 无传、失考、迁居未详 | 后代不明，往往是查找的突破口 |
| 葬某处，某山某向 | 墓地位置 |
| 世、代 | 以始祖为第一世往下数；不同谱起点不同，换谱时要换算 |

## 海外拼写

早期出洋的人多讲粤语、闽南话、客家话，外国档案按方言拼音记录，拼法也不统一：

| 字 | 常见拼法 |
|---|---|
| 陈 | Chan（粤）、Tan（闽南）、Chin、Chen |
| 林 | Lam（粤）、Lim（闽南）、Lin |
| 黄 | Wong、Ng（粤）、Ooi、Wee（闽南）、Huang |
| 李 | Lee、Li、Lei |
| 张 | Cheung（粤）、Teo、Chong、Chang、Zhang |
| 刘 | Lau（粤）、Low、Lew、Liu |

还要注意：

- 外国官员常把名字的最后一个字当成姓，或把“阿”（Ah）当名字的一部分，例如 Ah Foo 可能是“阿福”。
- 同一个人在不同档案里拼法可能不同，查索引时把几种拼法都试一遍。
- 找到外文档案后，用信件、侨批、族谱上的中文名对照，确认是同一个人。
