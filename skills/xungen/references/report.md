# 报告和信件模板

## 研究报告

交付时用这个结构，写进 `report.md`（或用户要的格式）。报告只写有出处的内容，推测和传说单独标出。

```markdown
# 〔家族〕家史研究报告

〔日期〕 · 研究问题：〔例如“曾祖父陈振华在澳洲的经历和他父亲的名字”〕

## 结论

〔三五句话：查到了什么，确定程度如何。〕

## 世系图

![世系图](tree.svg)

## 逐代说明

### 第〔N〕世 〔姓名〕

- 生卒：〔年份〕（原文“〔原文〕”，出处 〔s1〕）
- 关系：〔父、母、配偶、子女〕，依据 〔出处〕
- 证据状态：〔互证 / 单一来源 / 口述 / 推测 / 有矛盾〕
- 〔其他事迹，每条注出处〕

## 矛盾和未解决的问题

- 〔两个说法分别是什么，各自出处，目前倾向哪个，为什么〕

## 传说

- 〔族谱或口述里的始祖、迁徙传说，注明“族谱记载，未考证”〕

## 查过但没找到

- 〔查了什么、用什么关键词、日期〕。这一节很重要，下次不用重复查。

## 下一步

1. 〔最有希望的线索，去哪里查，需要带什么〕
2. 〔要问哪位长辈什么问题〕

## 出处

- s1 〔名称，收藏地，卷页或档案号〕
```

## 信件

只起草，由用户决定发不发。信要短，开头说明身份和来意，给出能帮对方查找的具体信息，结尾留联系方式。

### 写给档案馆、图书馆

```
〔机构〕负责同志：

您好！我是〔姓名〕，正在整理家族史，想查询〔祖先姓名〕的相关档案。

已知信息：
- 姓名：〔中文名〕（可能的写法：〔其他写法〕）
- 生卒：约〔年份〕—〔年份〕
- 籍贯：〔当时地名〕（今〔今地名〕）
- 可能相关的事件：〔例如“1914 年前后出洋”“民国时期在某校任教”〕

想请问贵馆是否藏有相关的〔户籍 / 侨务 / 学校 / 地籍〕档案，查阅需要什么手续和证件，能否远程申请复制。

谢谢！
〔姓名〕〔联系方式〕
```

### 写给宗亲会、族谱持有人

```
〔称呼〕您好！

我是〔祖籍〕〔姓〕氏后人，〔几〕世祖是〔名字〕（字辈“〔某〕”），〔父辈、祖辈〕从〔地方〕迁到〔地方〕。

听说您那里保存有〔族谱名称〕。想请教两件事：
1. 谱里有没有〔祖先名字〕这一支的记载？
2. 方便的话，能否拍几页相关的世系给我参考？

我这边整理的世系也可以分享给您，供续修参考。
〔姓名〕〔联系方式〕
```

### 写给海外档案馆（英文）

```
Dear Reference Team,

I am researching my great-grandfather, [Chinese name] (possibly recorded as [romanised spellings]),
born about [year] in [county, e.g. Sunning/Toishan], Guangdong, China.
He lived in [city] from about [year] to [year] and returned to China in about [year].

Could you tell me whether you hold records about him, such as [record type, e.g. CEDT files,
immigration case files], and how I can obtain copies?

Thank you for your help.
[Name], [email]
```
