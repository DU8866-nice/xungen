# 国内资料：去哪里查

按“离家越近越先查”的顺序排。每个入口都写明了能查到什么、要注意什么。链接和规则核对于 2026 年 11 月，查之前打开官网确认最新情况。

## 1. 现成的族谱

先问家里、本村祠堂和宗亲会有没有族谱。没有的话，按“姓氏＋县名”查公共收藏。族谱名称五花八门：家谱、族谱、宗谱、家乘、支谱、房谱、世谱、通谱，检索时都试一下，也试试堂号和郡望。

| 收藏 | 说明 |
|---|---|
| 上海图书馆家谱知识服务平台 | 上海图书馆收藏的中文家谱原件数量居世界公藏机构首位，大部分已数字化编目。可从上海图书馆官网 www.library.sh.cn 进入。2016 年起已向全球免费开放 2500 多种家谱全文。 |
| 国家图书馆：中华寻根网、中华古籍资源库 | 中华寻根网提供家谱书目、人物索引和部分家谱影像；中华古籍资源库（http://read.nlc.cn）免登录可看古籍、地方志、家谱等资源。 |
| FamilySearch：China, Collection of Genealogies | 免费，按姓氏和地区浏览中国家谱影像，来自中国、北美和东南亚的机构与私人收藏：https://www.familysearch.org/search/collection/1787988 。部分影像要登录账号或到家谱中心查看。 |
| 省市图书馆家谱中心 | 例如广州图书馆家谱查询中心，现场可查本地姓氏族谱。打电话问开放时间和预约要求。 |
| 《中国家谱总目》 | 上海图书馆主编的全国家谱联合目录，能查到某姓某地的谱现藏哪里。大型图书馆有纸本。 |

找到同姓同县的谱后，先核对字辈诗、迁徙记载和堂号，确认是不是本支，再找具体的人。

## 2. 地方志

县志、府志里有建置沿革、地名、人物传、选举（科举）、职官、烈女、忠义等名单，祖上做过官、中过举、参过军，常能在这里找到。

- 旧志：中研院“中國大陸各省地方志書目查詢系統”可查某县有哪些旧志、藏在哪里。
- 新编地方志（1980 年代以后）：多数省份的地方志网站可以在线阅读，目录可参考 https://gitee.com/hdeping/difangzhi 。
- 学校和图书馆常订有中国方志库、万方地方志等收费数据库，可以到馆使用。

## 3. 古代官员和士人

祖上是明清官员、举人、进士或文人，查中国历代人物传记资料库（CBDB，哈佛大学、中研院、北京大学合作，收录 60 多万人）：https://cbdb.fas.harvard.edu/cbdbapi/person.php?name=人名 。它记录别名、籍贯、官职和亲属关系，每条都注出处。

## 4. 档案馆

- 《档案法》（2021 年施行）规定，县级以上各级档案馆的档案，自形成之日起满 25 年向社会开放；涉及国家安全等的可以延期。
- 县、市档案馆可能存有民国时期的户籍、地籍、学校、侨务等档案。开放程度和查阅手续各地不同，先打电话问清楚要带什么证件。
- 公安户籍档案、人事档案一般不对外开放查询，不要把它们当成可查的渠道。

## 5. 烈士和军人

| 资料 | 说明 |
|---|---|
| 中华英烈网 | 退役军人事务部主管，载有一百多万名烈士的基本信息和烈士陵园资料：http://www.chinamartyrs.gov.cn |
| 南京抗日航空烈士纪念馆名录 | 已公布 1470 名中国籍抗日航空英烈的姓名、籍贯和生卒年 |
| 《抗战阵亡将士名录》 | 民间团队历时 5 年，从中华英烈网、地方志、陵园刻名等七十多万条资料中核实出 32.15 万名抗战阵亡将士，编成 23 册 |
| 各地烈士陵园、英名墙 | 不少省市有在线烈士名录，例如贵州的“烈士英名录” |

国民革命军阵亡将士不一定都在官方烈士名录里，要同时查地方志和民间整理的名录。

## 6. 侨批、银信

侨批是海外华侨寄回家的汇款加家书，2013 年列入联合国教科文组织《世界记忆名录》。主要藏在广东、福建两省：

- 广东省档案馆、汕头、江门、梅州等地档案馆；
- 汕头大学图书馆、潮汕历史文化研究中心的侨批数据库；
- 江门五邑华侨华人博物馆（五邑银信）。

公共收藏大多不能按人名在线检索。最有用的是家里自己留下的侨批：看寄批人和收批人的名字、海外地址、侨批局名称和日期，再去对照海外档案。

## 7. 墓碑、祠堂、碑记

- 墓碑：正面、背面、侧面都拍，背面常刻立碑子孙名单。
- 祠堂：神主牌、修祠碑记、捐款芳名录都能补世系。
- 不要自己做拓片或清洗古碑，容易损坏；需要时请当地文物部门或有经验的人帮忙。

## 8. 台湾、香港、澳门

- 台湾：日治时期的户口调查簿和光复后的除户誊本，直系血亲可以带身份证明到户政事务所申请；日治户籍上的年份用日本年号，用 `when.py` 换算。
- 香港、澳门：先查家中证件、教会和学校记录、坟场记录，再查政府档案机构的公开目录。

## 9. 宗亲会和寻根服务

- 宗亲会、姓氏研究会消息多、谱多，但他们整理的“统谱”“通谱”常把同姓不同宗的家族接在一起，引用前按 [evidence.md](evidence.md) 核对。
- 收费修谱、寻根公司：先问清楚每一代的出处。拿不出原件或照片的世系，不要接到自己家谱上。
