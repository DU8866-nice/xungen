# 长辈访谈和家中实物

查家史最快的资料在家里：长辈的记忆和抽屉里的旧东西。档案馆和族谱都要靠这里得到的名字、村名和年份才能查。

## 访谈前

- 先找家里年纪最大的人，越早越好。
- 征得同意再录音。录音比笔记可靠，方言地名和名字也能以后再听。
- 准备好已经知道的世系草图，让长辈在图上指认和补充，比空问容易得多。
- 春节、清明、婚丧聚会时人最齐，一次能问多位老人，还能互相纠正。

## 记录方法

每条信息记下四件事：

1. 说了什么，尽量照原话记，包括方言叫法；
2. 谁说的，什么时候说的；
3. 他怎么知道的：亲眼见过、听长辈说、还是看过族谱或证件；
4. 原话里的地名、人名用方言念一遍，记下发音（拼音或粤拼、白话字都行），海外档案常按方言拼写。

不同长辈说法不一样时，两种都记下来，不要当场替他们统一。

## 问题清单

按需挑选，不必全问。

**本人这一代和父母**
- 父母的全名、小名、出生年份和地点（问农历还是公历、属什么）。
- 兄弟姐妹几个，排行第几，包括夭折和送养的。

**祖父母、外祖父母**
- 全名，有没有字、号、谱名、小名。
- 生年、属相、去世年份，葬在哪里。
- 做什么营生，住过哪些地方，经历过哪些大事（参军、逃难、出洋、下乡、迁居）。
- 外婆、奶奶娘家姓什么，娘家在哪个村。

**曾祖及以上**
- 能叫出名字的最早一代是谁？“太公”“阿太”是哪一位？
- 家里或村里的字辈诗能不能背出来？你们这一代是哪个字？

**祖籍和迁徙**
- 祖籍具体到哪个县、哪个镇、哪个村？村名有没有改过？
- 祖上什么时候、为什么搬到现在的地方？
- 家族有没有“从某地迁来”的说法（例如大槐树、珠玑巷）？这类说法单独记，见 [evidence.md](evidence.md)。

**宗族和族谱**
- 有没有族谱、谱单、祠堂、宗亲会？谁家保管？最近一次修谱是哪年？
- 堂号是什么（例如某某堂），门楣、灯笼、祖先牌位上写什么？

**墓地和祭祀**
- 祖坟在哪里？墓碑上刻了什么？有没有迁过坟？
- 神主牌、祖先牌位还在吗？

**海外亲属**
- 有没有人去过南洋、美国、加拿大、澳洲、新西兰？什么年代，在哪个城市，做什么？
- 有没有寄回来的信、侨批、照片、汇款单？用的什么外文名字？

## 实物清单

拍照时整件拍，正反面都拍，再拍局部特写；不要剪裁掉页码、印章和落款。

| 实物 | 能查到什么 |
|---|---|
| 族谱、谱单、手抄世系 | 世系、字辈、迁徙、祖籍、葬地 |
| 墓碑（正面、背面、侧面落款） | 名讳、生卒年、立碑子孙名单、籍贯 |
| 祖先牌位、神主牌 | 名讳、生卒、排行 |
| 老户口簿、户口迁移证、粮油关系 | 姓名、出生日期、籍贯、迁移时间 |
| 结婚证、毕业证、工作证、军人证件 | 生年、籍贯、单位、经历 |
| 地契、房契、分家书（阄书） | 兄弟关系、地名、年代 |
| 侨批、家书和信封 | 海外住址、寄批人和收批人、侨批局、年份 |
| 讣告、挽联、追悼会名单 | 亲属关系、生卒年 |
| 老照片（看背面题字） | 人名、地点、年份、照相馆所在城市 |

## 访谈后

- 当天把录音和笔记整理成文字，标明来源，存进 `sources`，例如 `{"id": "s5", "title": "大伯口述（2026 年春节）", "kind": "oral"}`。
- 把新得到的人和关系写进 `family.json`，跑一次 `family.py check`，看下一次该问什么。
