# 证据和常见陷阱

家史研究最常见的错误不是查不到，而是把查到的东西接错了人，或把传说写成了事实。每条结论都要说得出出处，说不出就标清楚是推测。

## 出处分三类

| 类型 | `kind` | 例子 |
|---|---|---|
| 原始记录 | `original` | 当时留下的东西：墓碑、证件、户口簿、档案原件、侨批、当代修的族谱里对同时代人的记载 |
| 转录、索引、后修 | `derivative` | 后人抄录或整理的：网上转抄的世系、数据库索引、几百年后修的谱对远代祖先的记载 |
| 口述 | `oral` | 长辈的回忆、家族说法 |

同一份记录的不同副本算一个来源，例如同一部族谱的两个版本、网上几个网站互相转抄的世系。在 JSON 里给它们相同的 `group`，脚本就不会把它们算成两个独立出处。

## 每个人的证据状态

`family.py` 按出处自动算，也可以在 `status` 里手动指定：

| 状态 | 含义 |
|---|---|
| `corroborated` 互证 | 两个以上独立出处一致 |
| `single` 单一来源 | 只有一个书面出处 |
| `oral` 口述 | 只有口述或没有出处 |
| `hypothesis` 推测 | 根据线索推断，还没有记录直接说明 |
| `contradicted` 有矛盾 | 出处之间冲突，还没解决 |

写报告时，“互证”的可以直接陈述，“单一来源”要注明出处，“口述”和“推测”必须写明是口述或推测。

## 矛盾怎么处理

1. 两个说法都记下来，不要只留一个。
2. 看哪个更接近事件发生的时间、记录者是不是亲历者。墓碑和当时的证件通常比几十年后的口述可靠。
3. 年份差一两年，先检查虚岁、农历年底跨年、年号换算（见 [dates.md](dates.md)）。
4. 解决不了的，标 `contradicted`，写进待查清单。

## 同名同姓

同一个村、同一代里同名的人很多。合并两条记录之前，至少要有一项能区分的信息一致：父亲名字、配偶、生年、住址、子女。只是名字相同，就保留成两个人。

## 常见陷阱

**攀附名人始祖。** 很多族谱把始祖接到某位古代帝王、名臣或名人身上。学界普遍认为，族谱的远代世系多为后世修谱时追述，有不少是附会。没有同时代原始记录的远祖，标 `"legend": true`，报告里写成“族谱记载”而不是事实。`family.py check` 会对明代以前、只有后世记录的人给出提醒。

**联宗、统谱。** 同姓的几个家族合修“统谱”“通谱”时，可能把本无血缘关系的支派接到一起。用统谱时，只信能和本支原谱对上的部分。

**迁徙传说。** 山西洪洞大槐树、广东南雄珠玑巷、江西瓦屑坝、湖北麻城孝感乡、“湖广填四川”等说法出现在大量族谱里。学者认为其中相当一部分是后来形成的集体记忆，单凭族谱里的一句话，不能确定本家真的从那里来。

**口述的偏差。** 年份常差几年，辈分容易记串，叔伯和祖父容易搞混。口述是线索，要找书面记录印证。

**名字变来变去。** 谱名、日常名、字号、外文名、同音字都可能是同一个人，见 [names.md](names.md)。

**过继和入赘。** 过继的人在生父和嗣父两边的记载不同，入赘家庭的子女可能随母姓。代数、年龄对不上时，先想到这两种情况。

**纸生仔。** 美国排华时期很多人用买来的身份入境，档案上的父子关系可能不是血缘关系，见 [sources-overseas.md](sources-overseas.md)。

**网上的世系和寻亲群。** 只当线索，必须找到原件或照片。

**收费修谱、寻根服务。** 每一代都要求给出出处。拿不出原件或照片的世系，不要接到自己家谱上。

## DNA

基因检测（尤其是父系 Y 染色体）能检验“这两支是不是同一父系”这类具体假设，但不能证明家族是某位古人的后代。基因数据是敏感信息，检测前看清服务商怎么保存和使用数据，不要替别人上传他们的数据。
